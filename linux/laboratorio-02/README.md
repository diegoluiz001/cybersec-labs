Laboratório: 02 — Permissões, Usuários e Grupos

Hoje estudei permissões, usuários e grupos no Linux. Pratiquei o uso de chmod, chown, chgrp, adduser, usermod, id e sudo -u.

Durante o laboratório, criei um segundo usuário e um grupo para testar diferentes níveis de acesso a arquivos. Consegui entender melhor a diferença entre proprietário, grupo e outros usuários, além de perceber que as permissões dos diretórios também influenciam o acesso aos arquivos.

Tive algumas dificuldades durante os testes, principalmente para entender o funcionamento dos grupos na sessão e a diferença entre acessar e criar arquivos em um diretório. A prática ajudou a esclarecer esses conceitos.

Conclusão: consegui entender melhor como o Linux controla o acesso aos arquivos e como grupos podem ser utilizados para compartilhar permissões entre usuários.

Próximo passo: continuar estudando administração e segurança no Linux, avançando para processos e serviços.
