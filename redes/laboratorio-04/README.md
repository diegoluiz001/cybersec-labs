Laboratório: 04 — Portas, Sockets e Conexões

Resumo:
Pratiquei a identificação de portas, protocolos e conexões utilizando o ss. Aprendi a diferenciar TCP e UDP, os estados LISTEN e ESTAB e a relação entre processos, sockets, IPs e portas. Também criei um servidor HTTP local com Python, acessei com curl e observei a comunicação utilizando tcpdump.

Dificuldades:
Tive dificuldade principalmente para entender o conceito de socket e diferenciar o endereço IP do servidor que oferece o serviço. A prática com o servidor Python ajudou a visualizar melhor esses conceitos.

Conclusão:
Consegui compreender melhor como um processo utiliza sockets para se comunicar pela rede e como identificar cliente, servidor, portas locais e remotas. A captura do tráfego ajudou a visualizar na prática uma requisição e uma resposta HTTP.
