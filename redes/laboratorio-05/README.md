Dificuldades:

Conclusão:
Consegui entender melhor o caminho de uma consulta DNS e como identificar quando a resolução de nomes está funcionando ou apresentando falhas. A revisão dos conteúdos anteriores também ajudou a reforçar pontos que ainda não estavam bem fixados.
