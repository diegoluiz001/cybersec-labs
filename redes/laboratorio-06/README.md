Laboratório: 06 — TCP e Análise de Conexões

Resumo:
Estudei o funcionamento do protocolo TCP e suas diferenças em relação ao UDP. Utilizei um servidor HTTP local em Python e o tcpdump para capturar e analisar uma conexão real, identificando o Three-Way Handshake, a transmissão de dados e o encerramento da comunicação.

Dificuldades:
Tive pequenas dificuldades para diferenciar requisições e respostas HTTP e identificar corretamente qual dispositivo iniciou o encerramento da conexão. Consegui compreender esses pontos durante a análise dos pacotes.

Conclusão:
Consegui interpretar o estabelecimento e o encerramento de uma conexão TCP, identificando clientes, servidores, portas e flags. A prática ajudou a compreender melhor como os dispositivos se comunicam e como analisar o tráfego de rede.
